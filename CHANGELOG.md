# Changelog

## [v1.0.0] - 2026-08-18
### Initial Release - EZ-Game-Chat
- **Auto-Typer & Voice-Line Studio**: Fast in-game chat messaging with customizable delays and hotkeys.
- **Quote Categories & Editor**: Fully custom quotes and categories, ASCII emoticons, and multi-language support (English, Polish, Spanish, Portuguese, German).
- **Target Nickname Studio**: Live placeholder replacement (`{name}`, `{target}`, etc.) with custom player nicknames.
- **Visualizer**: Real-time on-screen keyboard visualizer for bound keys.
- **Low-Level System Shortcut Blocker**: Optional hook to suppress accidental Windows/Ctrl/Alt system keys during games.
- **Modern Dark UI**: Powered by CustomTkinter with drag-and-drop custom icon support.
