# Project Rules

- **Quote Character Limits**: No quote in `quotes.json` (or quote collections in this project) may exceed **72 characters** total.
- **Nickname Placeholder Limit**: If a quote includes a nickname placeholder (such as `{name}`, `{nick}`, `<nick>`, `{nickname}`, etc.), the raw template string must NOT exceed **65 characters** max (to leave margin for variable nickname lengths when inserted).
